# Ocassio.Project

**Live:** https://ocassio-project.vercel.app · **Deployment guide:** [DEPLOYMENT.md](./DEPLOYMENT.md)

**Ocassio.Project** is a professional photography and visual storytelling web application founded by **Yehuda Alfa**, a photographer focused on capturing meaningful moments through photography and film.

The platform is designed as more than a traditional photography portfolio. It acts as a complete digital presence for Ocassio.Project, allowing visitors to discover Yehuda’s work, understand the services offered, explore previous and ongoing projects, review pricing and workflow information, and submit project inquiries directly through the website.

## Purpose

Ocassio.Project was created to solve the problem of fragmented portfolio presentation and client communication.

Instead of relying on separate Instagram posts, WhatsApp messages, Google Drive folders, price lists, and manually shared project information, the website brings everything together into one professional platform.

The main goal is to create a clear journey for potential clients:

**Discover → Explore → Understand → Trust → Start a Project**

## Main Website Content

The website includes:

- **Home** — selected work, featured projects, services, showreel, current projects, journal content, and primary calls to action.
- **Work** — the complete photography and film portfolio.
- **Project Detail** — individual project stories containing photography, video, project information, behind-the-scenes content, and credits.
- **Services** — photography, film, commercial campaigns, portraits, product photography, events, and creative production.
- **Pricing** — starting prices, packages, deliverables, and custom quotation information.
- **Process** — a clear explanation of how clients work with Ocassio.Project from inquiry to final delivery.
- **About** — information about Ocassio.Project, Yehuda, the studio philosophy, team, clients, and recognition.
- **Journal** — project stories, behind-the-scenes content, photography, film, and studio updates.
- **Now** — projects currently in production and upcoming releases.
- **Contact** — general contact information and social channels.
- **Start a Project** — a structured inquiry form where potential clients can submit their project requirements.
